作品简介

出行安排要兼顾客户地址、固定时间、空档和多人接送，手动查图算路费时。小径让用户说一句话，文心ERNIE（千帆）只把它填进锚点、时间、要找的东西、偏好、缺口五栏，追问和编排由代码决定，地点、路程、营业时间都来自百度地图。支持出差见客户、定时行程与空档处理、碎片时间推荐、拼车倒推下楼时间与分享页、开放式推荐。用到百度地图地点检索、地理编码、批量算路、路线规划（驾车/步行/公交）和JS API GL。

用到的百度地图 API

  • 地点检索 place/v2/search：酒店、活动地点、任务雷达；点名地点核对
  • 地理编码 geocoding/v3
  • 批量算路 routematrix/v2（步行 / 驾车 / 骑行）：酒店×地点通勤、拼车接人顺序
  • 路线规划 direction/v2/driving（含途经点）、direction/v2/riding、directionlite/v1/walking、direction/v2/transit（公交/地铁）
  • JavaScript API GL：雷达圈、路线、计划总览、拼车地图
  • 大模型：千帆 v2 chat/completions（文心 ernie-4.5-turbo-128k，只做理解）；千帆「百度搜索」ai_search/web_search（开放式场景的近期活动，场馆再用百度地点检索核对）
